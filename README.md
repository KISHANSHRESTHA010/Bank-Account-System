# 🏦 Bank Account System

A Object-Oriented Programming (OOP) based Bank Account Management System built with Python. Designed to demonstrate clean code principles, modular structure, and robust transaction handling.

---

## ✨ Features

- 👤 **Account Creation:** Easily register new user accounts with secure tracking.
- 💳 **Deposit & Withdrawal:** Perform seamless financial transactions with automatic balance updates.
- 📊 **Balance Enquiry:** Quick and easy check of real-time account balances.
- ⚙️ **OOP Principles:** Built using core Object-Oriented paradigms (Encapsulation, Inheritance, and Abstraction).

---

## 🛠️ Tech Stack

- **Language:** [Python 3.x](https://www.python.org/)
- **Paradigm:** Object-Oriented Programming (OOP)
